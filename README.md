# DealMind — AI Deal Intelligence Agent

> **An AI sales intelligence agent powered by Hindsight Cloud persistent memory that remembers customer interactions across deal cycles, detects compounding deal risks, and recommends decisive salesperson actions.**

Full source code and application are located in [`DealMind/`](./DealMind/):
- **Backend:** [`DealMind/backend`](./DealMind/backend) (Node.js + Express + Official `@vectorize-io/hindsight-client`)
- **Frontend:** [`DealMind/frontend`](./DealMind/frontend) (React 18 + Vite + Tailwind CSS + Lucide React)

Refer to the main [DealMind README](./DealMind/README.md) for full architecture, installation, Hindsight setup, and demo instructions.
